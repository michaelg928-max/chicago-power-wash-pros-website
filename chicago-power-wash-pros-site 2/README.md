
# Chicago Power Wash Pros Website

## Deploy To Vercel

1. Download this ZIP
2. Unzip it
3. Go to https://vercel.com/new
4. Drag the folder into Vercel
5. Click Deploy

## Connect Hover Domain

Inside Vercel:
- Go to Project Settings
- Domains
- Add:
  www.chicagopowerwashpros.com

Then copy the DNS records into Hover DNS settings.
